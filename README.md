# دوبله‌یار فارسی — شروع پروژه اندروید

این یک اسکلت اولیه‌ی رابط کاربری Android با Kotlin و Jetpack Compose است؛ هنوز موتور واقعی ترجمه، تشخیص گوینده و تولید صدا به آن متصل نشده است.

## شروع
1. Android Studio را نصب کنید.
2. یک پروژه‌ی Empty Activity با Kotlin و Jetpack Compose بسازید.
3. فایل `MainActivity.kt` را با فایل این بسته جایگزین کنید.
4. در صورت نیاز نام package را با پروژه‌ی خود هماهنگ کنید.

## مسیر نسخه‌ی واقعی
- انتخاب ویدیو: Android Photo Picker / Activity Result API
- تبدیل گفتار به متن: موتور ASR چندزبانه
- ترجمه‌ی دیالوگ‌ها: سرویس ترجمه یا مدل محلی
- تشخیص/تفکیک گوینده: diarization
- صدای فارسی جداگانه برای هر شخصیت: موتور TTS با صداهای مجاز
- ترکیب صدا و ویدیو: FFmpegKit یا پردازشگر سمت سرور

## نکته
این نسخه نمایشی است. دکمه‌ی «شروع دوبله» فعلاً وضعیت نمونه نشان می‌دهد و فایل ویدیویی تولید نمی‌کند. شبیه‌سازی صدای افراد واقعی باید فقط با رضایت و مجوز مناسب انجام شود؛ برای نسخه‌ی اول، صداهای مصنوعی از پیش تعریف‌شده امن‌تر و ساده‌ترند.
